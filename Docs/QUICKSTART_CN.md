# RimAI.Quests — quick start

1. Build/deploy from the RimAI integration workspace (`tools\verify-all.ps1`).
2. Enable Harmony, RimAI Core/Communication host mods, then `RimAI.Quests`.
3. Configure gameplay AI credentials via RimAI settings (`OPENAI_RIMAI`).
4. Start or load a game; new quest descriptions may stream when quests generate.

Historical donor install guides that assumed a standalone RimTalk dependency are obsolete.
